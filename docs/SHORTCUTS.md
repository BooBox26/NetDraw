# NETDRAW keyboard shortcuts

Cheat sheet for the most common shortcuts. All are active when the canvas has
focus and no input is being edited.

## Global

| Shortcut               | Action                             |
| ---------------------- | ---------------------------------- |
| `Ctrl/Cmd + Z`         | Undo                               |
| `Ctrl/Cmd + Y`         | Redo                               |
| `Ctrl/Cmd + Shift + Z` | Redo                               |
| `Ctrl/Cmd + D`         | Duplicate selection                |
| `Ctrl/Cmd + A`         | Select all shapes                  |
| `Ctrl/Cmd + E`         | Export current page as SVG         |
| `Ctrl/Cmd + S`         | (browser) — we use the in-app Save |
| `Delete` / `Backspace` | Delete selection                   |
| `Escape`               | Clear selection, cancel action     |
| `Space` (hold)         | Pan mode (drag the canvas)         |

## Tools

| Shortcut | Tool      |
| -------- | --------- |
| `V`      | Select    |
| `H`      | Pan       |
| `C`      | Connector |

## View

| Shortcut           | Action         |
| ------------------ | -------------- |
| `0`                | Fit to content |
| Mouse wheel        | Pan            |
| `Ctrl/Cmd + Wheel` | Zoom at cursor |
| Pinch (touch)      | Zoom at cursor |

## Editing

| Shortcut            | Action            |
| ------------------- | ----------------- |
| Double-click shape  | Edit text inline  |
| Drag anchor point   | Start a connector |
| Shift + drag handle | Constrain aspect  |
| Shift + rotate      | Snap rotation 15° |

## Tips

- Multi-select with **Shift** + click.
- Marquee select: click an empty area and drag.
- Right-click for the context menu (duplicate, send to back, …).
- Use the **Layers** panel at the bottom to organize complex diagrams.
- All undo/redo is grouped: a 2-second drag is a single undo entry.
